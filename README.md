## Вимоги

У вас повинний бути скачений Python.
Скрипт використовує pyatogui, щоб знайти кнопку на скріні.

1. Рекомендую це відео, де ви зможете покроково завантажити собі Python - https://www.youtube.com/watch?v=ddGTXBhaGWA
2. Якщо у вас не завантажений по якигось причинах ця бібліотека, завантажте:
   ```bash
   pip install pyautogui opencv-python
   
## Як використовувати?
   Завантажте репозиторій (Code -> Download ZIP).

Важливо: Візьміть краще ваш скриншот кнопки Slow Download на вашому скріні, акуратно треба виділити кнопку без білих полосок, але можна й зними.
Збережіть цей скріншот як knopka.png і поставте це в ту саму папку де й скрипт, який ви завантажили в мене. Можна в любій папці ці два файли зберегти, головне щоб вони були обоє в папці.

Запустіть Wabbajack і нажміть на install чи що там має бути, коли з'явиться віконце з нексус там де треба нажати на Slow Download, то запускаємо скрипт.
В папці, де ваших два файли нажимаєте ПКМ ( Праву кнопку миші ) і натискаєте на відкрити термінал. Якщо по якигось причинах ви такого не можете зробити, тоді в пошуку віндовса пишите cmd або powershell, відкриваєте з правами адміністратора або без, але краще з правами.
Потім пишите команду cd (ваш шлях до папки), наприклад: cd C:\Automatic wabbajack.
Нарешті відкрили термінал і вводите таку команду:
```bash
python klicker.py
